# AI-Powered Software Audit Management System

## 1. Project Overview

**Project Name:**
AI-Powered Software Audit Management System

**Project Type:**
Full-stack Python application (desktop/web application)

**Problem Statement:**

Many organizations still manage software audits manually using Excel sheets or documents. This approach is:

* Time-consuming
* Difficult to track
* Error-prone
* Hard to analyze
* Difficult to generate reports

This project digitizes the audit process by allowing users to create projects, perform audits using predefined checkpoints, store audit records, and visualize project health through dashboards.

# 9. Why TinyDB?

Interview Question

Why TinyDB instead of SQLite?

Good answer

> I chose TinyDB because this application is a lightweight desktop application with a single user. It stores data in JSON format while providing a simple database API. It reduced setup complexity and allowed me to focus on application logic. For a production system with multiple users, I would migrate to SQLite or PostgreSQL.

---

# 10. Why Streamlit?

Interview Question

Why Streamlit?

Answer

> Streamlit allows rapid development of interactive Python applications. Since the project mainly focuses on audit workflows and analytics rather than frontend development, Streamlit enabled me to quickly build a professional dashboard while keeping the code entirely in Python.
