# Assumptions

- The auditor will manually review the code and enter audit results.
- The application is used by a single user at a time.
- Project and audit data are stored locally using JSON files.
- The user has basic knowledge of running Python programs.
- The audit checkpoints are generic and may be customized based on project needs.
- This system does not automatically analyze code; it supports manual auditing.
- The system uses a lightweight Streamlit UI for demonstration purposes
  and is intended for local, single-user usage.
- The UI is kept simple and is not optimized for large-scale or multi-user environments.
